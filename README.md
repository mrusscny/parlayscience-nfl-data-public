# ParlayScience NFL Data (public)

Machine-readable JSON outputs from the ParlayScience NFL pipeline.
Published automatically Tuesday–Sunday at 8:00 AM ET during the season.

## Structure

```
outputs/
  latest/                 <- always the most recent run (point plugins here)
  2026-week-01/
  2026-week-02/
  ...
```

Each week folder is **overwritten** by every run that week. Git history
preserves prior runs.

## Files per week

| File | Contents |
|---|---|
| `_meta.json` | Week context, blend weights applied, concepts built |
| `_data_health.json` | Per-source row counts and health |
| `touchdown_radar.json` | Concept 1 |
| `rb_spotlight.json` | Concept 2 |
| `wr_spotlight.json` | Concept 3 |
| `position_matchups.json` | Concept 4 |
| `punt_radar.json` | Concept 5 |

## Consuming from a Figma plugin

```js
const BASE = "https://raw.githubusercontent.com/mrusscny/parlayscience-nfl-data-public/main/outputs/latest";
const data = await (await fetch(`${BASE}/touchdown_radar.json`)).json();
```

Always check `_meta.json` → `week.generated_at_et` before rendering, so a stale
board is visible rather than silent.

## Blending

Early-season numbers blend the prior season with the current one, because 17
games is a small sample. `_meta.json` reports the exact weights used, and every
blended value carries a `__flags` field (`rookie`, `limited_prior`,
`changed_team`, `no_prior_data`).
